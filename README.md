# S 赛开赛闹钟（Windows）

双击「启动S赛闹钟.cmd」，等待官网赛程加载，选中要看的对阵，再点「开始监控所选比赛」。
可以输入 T1、BLG 等队伍简称筛选，按住 Ctrl 可同时选多场。先点「试听 5 秒」确认声音和输出设备。

- 默认每 30 秒读取一次 LoL Esports 官网，范围为最近 2 天到未来 90 天的 Worlds 比赛。
- 官网将指定赛事 ID 标为 `inProgress` 时持续响铃并弹出窗口；点击「停止响铃」关闭声音，其他选定比赛继续监控。
- 时间均按北京时间显示。预定时间只供参考；比赛延迟不会因“到点”而误报。
- 这是整场系列赛（BO1/BO3/BO5）的开赛提醒。官网的进行中状态可能包含 BP，不保证恰好在进入峡谷的一秒触发，也不是每小局提醒。
- 选择已在进行中的比赛，会在下一次成功检查时立即提醒。已结束的比赛不会补响。网络异常会显示状态未知并自动重试（最多间隔 120 秒）。
- 同一场每次监控只提醒一次；再次点击开始监控是重新设置本次监控。上次选择会保存，重开程序后需要点击开始监控。
- 可以最小化窗口。监控期间请求 Windows 阻止自动睡眠，不阻止熄屏。手动休眠、关机、关闭程序、断网或系统静音都会影响提醒；不能自动唤醒关机电脑。
- 提醒延迟 = 官网更新延迟 + 网络请求时间 + 轮询间隔。不能保证与直播画面完全同步。

## 环境与命令行

Python 3.10 或更新版本，需包含 tkinter（Windows 官网 Python 安装包默认包含），无需 pip 安装依赖。

在此目录执行 `python worlds_alarm.py --check` 可检查真实官网赛程，不会发出声音。
执行 `python -m unittest -v` 可运行不联网、无声音的逻辑测试。

## 自定义

首次开始监控后，程序会生成 `settings.json`。可在关闭程序后编辑：

- `interval`：轮询间隔秒数，限制为 15–300。
- `sound_file`：可选，WAV 铃声的绝对路径或相对于此目录的路径。例如 `"sound_file": "my_alarm.wav"`。不填写则自动生成提示音。
- `query_id`、`client_version`：仅在官网升级接口时需要更新。

比赛使用唯一赛事 ID 绑定，不会把同一战队另一场对局当成已选比赛；TBD 对阵更新后继续跟踪同一 ID。
错误记录在 `alarm.log`，文件自动轮换。

## 数据来源与维护

来源：[LoL Esports 官网](https://lolesports.com/en-US/?league=worlds)。
2026-10-20 已在本机验证官网 `/api/gql` 的只读 `scheduleEvents` 查询，支持状态、对阵、时间和分页。
此接口来自官网公开前端，不是承诺长期兼容的开发者 API。没有使用私人 API 密钥或账户登录。
若官网修改查询 ID、字段或访问规则，脚本会明确显示错误而不会改用预定时间响铃，需要维护接口适配。

文件说明：`worlds_alarm.py` 是主脚本；`test_worlds_alarm.py` 为逻辑测试；`启动S赛闹钟.cmd` 为启动入口。

## 安卓手机通知（声音 + 振动）

1. 手机安装 **ntfy**：[官方安装说明](https://docs.ntfy.sh/subscribe/phone/)（含 Google Play、F-Droid 和官方 GitHub APK 入口）。
2. 重启本脚本，点击窗口下方「安卓手机推送设置」。点击「复制频道名」。
3. 手机 ntfy 点 **+** 添加订阅，服务器为 `https://ntfy.sh`，主题名填入电脑生成的 `worlds-...` 完整频道名。不要把整个网址填成主题名。
4. 在电脑勾选「比赛开赛时推送到安卓手机」，点击「发送手机测试通知」。确认手机实际收到通知，且有声音和振动，再保存设置。
5. 回到电脑，选择比赛并开始监控。开赛时电脑保持响铃，同时发送手机通知。电脑与手机不必在同一个 Wi-Fi，但都必须能连接 ntfy.sh。

推送优先级为 **5（urgent）**。在安卓的 ntfy 通知设置中，为对应优先级通道开启声音、振动、弹出通知；检查勿扰模式和通知音量。允许后台运行；如安装版本提供 Instant delivery，建议开启。F-Droid 版默认使用即时送达。锁屏一段时间后再测试一次，验证后台接收。

**「推送服务已接收」只代表服务端接受消息，不代表手机已收到。** 必须以手机实测为准。尚未在你的手机完成配对和接收验证。电脑程序需保持运行；手机端收到的是通知，不会像电脑闹铃一样无限循环响铃。

随机频道名保存在本机 `settings.json`。公共 ntfy 频道不要求登录，但知道该名字的人可以订阅和发布消息，因此不要公开频道名或配置文件。通知通过第三方 ntfy 服务传递。默认关闭手机推送，只有你启用或点击测试后才发送。

手机推送在独立线程执行，失败不会阻止电脑本地响铃；失败原因会显示在窗口底部。每条通知只发送一次，不自动重发，避免网络超时后重复振动；可在设置中手动重新测试。手机断网或系统限制后台时可能延迟，通知正文含检测时间供判断。若电脑或手机无法连接 ntfy.sh，当前接入方式不能正常送达。

实现文件：`android_push.py`；测试：`test_android_push.py`。
接口依据：[ntfy 发布接口](https://docs.ntfy.sh/publish/#publish-as-json)、[安卓通知及即时送达](https://docs.ntfy.sh/subscribe/phone/)。
